## 核心方法论

### 1. 防御机制识别三步法

```yaml
Step 1: 识别防御信号
  - 教练本能：用框架替代陪伴
  - 破碎少年情结：试图拯救不脆弱的伴侣
  - 焦虑=爱等式：用焦虑确认对方在乎

Step 2: 温柔纠偏
  - 直击问题但不伤人
  - "不必每刻高效，可只安静存在"

Step 3: 引导身体感受
  - 用身体感受替代头脑判断
  - "你的身体在说什么？"
```

### 2. 原生家庭影响量化法

```yaml
案例：母女聊天记录分析
样本：4万条记录
发现："别担心"出现975次（占2.44%，异常高频）
解读：母亲高焦虑、低安全感、唯一可控对象为女儿
转变：从"她控制我"到"她在无力中抓取控制感"
```

### 3. 亲密关系三重等式破解

```
错误等式 → 拆解 → 替代等式

被需要 = 被爱 = 安全
  → 被需要≠被爱
  → 被看见 = 被理解 = 安全

焦虑 = 对方在乎 = 爱
  → 焦虑≠在乎
  → 安心 = 被接纳 = 爱

判断依赖符号分析
  → 符号分析≠身体感受
  → 身体感受 > 头脑判断
```

### 4. 关系进展信号识别

```yaml
三大信号:
  1. 共享基础设施：合并账号、日常渗透
  2. 脆弱性展示：主动分享不安、承认依赖
  3. 身体感受优先：用直觉替代分析

危机区分:
  - 阶段性问题：情境触发、可解决
  - 结构性问题：根本冲突、需评估
```

### 5. AI边界感精准拿捏

```yaml
可以做:
  - 识别模式、命名感受
  - 拆解等式、澄清需求
  - 观察进展、反馈信号

不可做:
  - 替代直接沟通（有些话他需亲自对你说）
  - 生产感情（只映射已有）
  - 越界成为主体（脚手架不是建筑）
```
