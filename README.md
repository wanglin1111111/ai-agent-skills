## 核心方法论

### 1. Harness的本质：手脚而非大脑

```
核心理念：引擎（模型）需要机甲（Harness）才能行动

可以做:
  - 工具编排：按任务需求组合工具链
  - 状态管理：追踪执行进度、维护上下文
  - 错误处理：失败检测、重试机制、降级策略
  - 执行闭环：验证任务完成、输出结果

不可做:
  - 替代智能决策（这是模型的职责）
  - 生成创造性方案（这是模型的能力）
  - 定义任务目标（这是用户的需求）
```

### 2. Self-Evolution三阶段

```
阶段1：探索期（高成本、低稳定、0 Skill、强依赖）
  ├─ 特征：尝试多种执行路径
  └─ 输出：原始工作流数据

阶段2：压缩期（中成本、中稳定、增长Skill、中依赖）
  ├─ 特征：提取有效路径、去除冗余
  └─ 输出：可复用Skill、执行模板

阶段3：固化期（低成本、高稳定、固定Skill、弱依赖）
  ├─ 特征：路径固化、跨模型验证
  └─ 输出：可靠Skill库、稳定工作流

核心认知：
  ❌ 拟人化自主学习
  ✅ 知识压缩与路径固化
  ✅ 跨模型一致性输出
```

### 3. Multi-Agent协作原理

```yaml
单Agent三大局限:
  1. 上下文衰减：超50%上下文后性能指数级下降
  2. 任务偏航：执行中途偏离初始目标
  3. 缺乏验证：单点失效无法及时发现

Multi-Agent三大机制:
  1. 角色分工：主Agent+观察Agent+评审Agent
  2. 实时互检：执行Agent+监控Agent实时对比
  3. 重思考：执行→反思→调整→再执行

协作模板:
  场景1: 代码生成Agent + 测试Agent + Review Agent
  场景2: 执行Agent + 监控Agent
  场景3: 生成Agent + 评审Agent
```

### 4. Agent爆发双重动因

```yaml
动因1: 全民级事件推动
  案例: 春晚合作推动豆包渗透率跃升
  价值: 降低认知门槛、扩大用户基数

动因2: Open Cloud短板暴露
  短板: 稳定性不足、记忆缺陷（每日4点重置）、门槛高
  突破口: Hermes Agent极简可用+多层次记忆+强一致性
```

### 5. 中国AI生态现状

```yaml
进展:
  - 开源模型（MiniMax M2.7）全球Token日调用量显著份额
  - 与闭源模型（Claude Opus）性能差距快速收窄

差距:
  1. 任务定义科学性：缺乏专家深度参与
  2. 算力规模支撑：试错密度不足
  3. GDP渗透深度：停留边缘场景

机会:
  ✅ 垂直场景COI（挂号、打车）
  ⚠️ Agent运行环境（Sandbox、Memory）
  ❌ 底层基建（认证、支付）
```

### 6. 人类角色重新定义

```yaml
AI本质:
  AI ≠ 替代人类
  AI = 新型通用基础设施（解放人力）

类比:
  电力革命 → 解放体力劳动
  AI革命 → 解放重复劳动

人类新角色:
  1. 创造力（Creativity）：创造新知识、提出新范式
  2. 判断力（Taste）：定义价值标准、做出价值判断
  3. 目标定义（Goal Definition）：定义目标、提出需求

分工原则:
  AI: 重复性执行
  人类: 创造性决策
```

## 核心认知突破

### 1. Harness不是大脑

```
错误认知: Harness替代模型智能
正确认知: Harness释放模型能力

类比: 引擎需要机甲才能行动
```

### 2. Self-Evolution不是自主学习

```
错误认知: Agent像人一样自主学习
正确认知: Agent通过知识压缩固化有效路径

本质: 提升可靠性、降低干预成本、支撑模型可替换
```

### 3. Multi-Agent协作弥补单Agent局限

```
单Agent局限: 上下文衰减、偏航、无验证
Multi-Agent价值: 角色分工、实时互检、重思考

本质: 逼近人类"换角度复盘"的认知优势
```

### 4. AI是新型通用基础设施

```
错误认知: AI替代人类
正确认知: AI解放人力（如电力、蒸汽机）

案例: 银行ATM化未减少岗位，反而扩张服务网络
```
