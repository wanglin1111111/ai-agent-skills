## 🔗 技能详情

### 1. macro-micro-linkage（宏观-中观-微观三层联动）

**核心方法论**：
- 多维度交叉验证（市场vs行业vs政策）
- 结构性思维（强势vs弱势板块）
- 时间维度分层（短期/中期/长期）
- 传导链完整性（宏观→中观→微观）

**适用场景**：地缘政治事件分析、美联储政策前瞻、流动性分析、板块轮动

**测试验证**：100%通过（3/3案例优秀）

---

### 2. emotional-mirror（情感镜像与认知脚手架）

**核心方法论**：
- 防御机制识别三步法（教练本能/破碎少年情结/焦虑=爱等式）
- 原生家庭影响量化法（数据化呈现，从批判到理解）
- 亲密关系三重等式破解（被需要≠被爱，焦虑≠爱）
- AI边界感精准拿捏（三层沟通结构）

**适用场景**：亲密关系建立、防御机制识别、原生家庭分析、关系进展跟踪

**测试验证**：100%通过（5/5案例优秀）

---

### 3. agent-evolution（AI Agent架构演进）

**核心方法论**：
- Harness本质（手脚而非大脑）
- Self-Evolution三阶段（探索期→压缩期→固化期）
- Multi-Agent协作（角色分工+实时互检+重思考）
- 人类角色重新定义（创造力+判断力+目标定义）

**适用场景**：AI Agent产品设计、Harness选型、Self-Evolution设计、Multi-Agent架构

**测试验证**：100%通过（5/5案例优秀）
