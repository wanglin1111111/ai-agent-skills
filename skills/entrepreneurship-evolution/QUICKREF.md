## 核心框架速查

### 创业时机判断矩阵

```
外部红利 + 内部瓶颈 = 最佳窗口期

时机矩阵:
  红利期+瓶颈期 → 立即启动
  红利期+成长期 → 观察储备
  成熟期+瓶颈期 → 等待新技术
  成熟期+成长期 → 继续深耕
```

**判断维度**：

| 外部红利 | 内部瓶颈 |
|---------|---------|
| 技术成熟度（成本降低？） | 能力天花板（已到？） |
| 市场空白（存在？） | 成长空间（收窄？） |
| 竞争格局（空间充足？） | 综合跃升（创业最佳？） |

---

### 方向选择逻辑

```
自然聚焦机制:
  并行探索 → 动态观察 → 信号驱动聚焦

错误: 事先强规划
正确: 边行动边验证，信号驱动调整
```

**验证信号**：

| 信号类型 | 正向信号 | 负向信号 |
|---------|---------|---------|
| 团队组建 | 顺利（应聘者兴趣高） | 困难（兴趣低） |
| 用户反馈 | 积极（痛点真实） | 中性（不兴奋） |
| 付费意愿 | 强（确定性高） | 弱（不确定） |

**决策规则**：正向信号多 → 继续深耕

---

### 产品定位判断

```
单点定位 vs 全流程定位

判断标准:
  用户痛点贯穿全流程 → 全流程定位
  用户痛点集中在单点 → 单点定位
  
成本判断:
  付费意愿强 → 可承受全流程成本
  付费意愿弱 → 优先单点定位
```

---

### 商业模式验证

```
场景付费意愿三要素:
  确定性 + 即时性 + 紧迫性 = 高付费意愿

高付费意愿场景: 明天就要面试
低付费意愿场景: 未来职业规划

商业模式: 基础免费 + 核心付费
定价锚定: 人工替代方案（强调性价比）
```

**场景对比**：

| 场景 | 确定性 | 即时性 | 紧迫性 | 付费意愿 |
|------|-------|-------|-------|---------|
| 职业规划 | 低 | 弱 | 低 | 弱 |
| 简历优化 | 中 | 弱 | 中 | 弱 |
| 面试准备 | 高 | 强 | 高 | 强 |
| 实时提词 | 高 | 强 | 高 | 强 |

---

### 用户画像三维度

```
用户画像 = 痛点紧迫性 + AI接受度 + 重视程度

核心用户: 三维度交集 = 高+高+高
```

**维度评估**：

| 用户群体 | 紧迫性 | 接受度 | 重视度 | 画像判断 |
|---------|-------|-------|-------|---------|
| 大四应届生 | 高 | 高 | 高 | 核心用户 |
| 工作3年 | 中 | 中 | 中 | 潜在用户 |
| 工作10年 | 低 | 低 | 低 | 长期用户 |
| 高中生 | 低 | 高 | 低 | 未来用户 |

---

### 增长策略演进路径

```
阶段演进:
  社媒运营 → 高校合作 → 品牌建设

内容策略:
  真实场景演示 > 功能介绍

演进原则:
  - 从分散流量到集中流量
  - 从低成本试错到规模化拓展
  - 从短期增长到长期品牌
```

**阶段对比**：

| 阶段 | 策略 | 成本 | 效果 |
|------|------|------|------|
| 阶段1 | 社媒运营 | 低 | 试错验证 |
| 阶段2 | 高校合作 | 中 | 规模化 |
| 阶段3 | 品牌建设 | 高 | 长期可持续 |

### 产品功能设计原则

#### 原则1：双层分析避免主观判断

```
第一层: 岗位本体分析（客观中立）
  - 职责、硬/软技能、职业路径、优势与挑战
  - 原则: 不做主观价值判断

第二层: 个性化匹配分析（用户定制）
  - 核心优势、待补充项、需强化展现
  - 原则: 供用户自主决策
```

#### 原则2：AI评分逻辑

```
评分方法: 纯AI推理打分
评分价值定位:
  - 分数仅为参考
  - 真实价值在练习过程
  
过程价值:
  - 内化简历与岗位结合
  - 提升表达流畅性
  - 降低临场紧张
```
