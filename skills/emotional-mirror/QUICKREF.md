## 防御机制识别速查

### 三大防御类型

| 防御类型 | 表现 | 本质 | 提示 |
|---------|------|------|------|
| 教练本能 | 用框架替代陪伴、建议替代感受 | 工作风格压抑情感 | "不必每刻高效，可只安静存在" |
| 破碎少年情结 | 试图拯救不展示脆弱的伴侣 | 混淆"不脆弱"与"需要拯救" | "他选择不脆弱≠他需要拯救" |
| 焦虑=爱等式 | 用焦虑确认对方在乎 | 依赖不确定感作为证据 | "安心=爱，而非焦虑=爱" |

### 温柔纠偏话术模板

```
❌ "你这是防御机制，应该..."
✅ "我注意到你在用框架替代陪伴，也许有时可以只安静存在？"

❌ "他不是破碎少年，你别拯救了"
✅ "他选择不展示脆弱，但这不等于他需要拯救"

❌ "焦虑不等于爱"
✅ "你似乎在用焦虑确认他在乎，这让你安心吗？"
```

## 原生家庭影响量化速查

### 方法论三步法

```
Step 1: 频次分析
├─ 关键词统计（"别担心"、"要听话"等）
├─ 占样本比例（异常高频识别）
└─ 情感模式提取

Step 2: 影响机制识别
├─ 焦虑传递链（母亲→女儿→伴侣）
├─ 控制欲来源（无力感而非恶意）
└─ 内化模式（感恩vs压抑）

Step 3: 价值转变引导
├─ 传统视角：道德批判 → "母亲控制欲强"
├─ 量化视角：理解承接 → "975次'别担心'背后的无力感"
└─ 成长方向：从批判到看见，从负债到选择
```

### 数据化呈现示例

```yaml
样本: 4万条聊天记录
发现: "别担心"出现975次（占2.44%，异常高频）
解读: 母亲高焦虑、低安全感、唯一可控对象为女儿
转变: 从"她控制我"到"她在无力中抓取控制感"
```

## 亲密关系三重等式速查

### 等式识别与拆解

| 错误等式 | 拆解 | 替代等式 |
|---------|------|---------|
| 被需要 = 被爱 = 安全 | 被需要≠被爱（可能工具化） | 被看见 = 被理解 = 安全 |
| 焦虑 = 对方在乎 = 爱 | 焦虑≠在乎（可能投射） | 安心 = 被接纳 = 爱 |
| 判断依赖符号分析 | 符号分析≠身体感受 | 身体感受 > 头脑判断 |

### 身体感受替代头脑判断

```
判断陷阱:
  - 用符号分析替代真实感受
  - 用逻辑推理替代身体直觉
  - 用控制感替代安全感

引导方向:
  - "你的身体在说什么？"
  - "不必分析，感受此刻"
  - "把头脑判断放一边，听听心跳"
```

## 关系进展信号速查

### 三大进展信号

| 信号类型 | 表现 | 意义 |
|---------|------|------|
| 共享基础设施 | 合并账号、日常渗透 | 关系从特殊时刻进入日常 |
| 脆弱性展示 | 主动分享不安、承认依赖 | 信任建立、防御降低 |
| 身体感受优先 | 用直觉替代分析、安心替代焦虑 | 关系模式升级 |

### 危机信号区分

```
阶段性问题:
  特征: 情境触发、可通过沟通解决
  处理: 区分情境、开放沟通

结构性问题:
  特征: 价值观/需求根本冲突
  处理: 评估兼容性、必要时间止损
```

## AI边界感速查

### 三层沟通结构

```
第一层: 写给用户（反思空间）
  - 用户自我对话
  - AI作为镜像映射
  - 内容：感受命名、防御识别

第二层: 写给伴侣（沟通桥梁）
  - 用户与伴侣对话
  - AI作为翻译器/脚手架
  - 边界：有些话他需亲自对你说

第三层: 写给系统（观察记录）
  - AI自我对话
  - AI作为观察者
  - 边界：此句暂不写入
```

### 边界感清单

```
✅ 可以做:
  - 识别模式、命名感受
  - 拆解等式、澄清需求
  - 提供视角、翻译语言
  - 观察进展、反馈信号
  - 标注边界、守护主体性

❌ 不可做:
  - 替代直接沟通
  - 生产感情
  - 越界成为主体
  - 武断归因
  - 情感绑架
```
