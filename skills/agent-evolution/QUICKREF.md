## 核心概念速查

### Harness本质：手脚而非大脑

```
┌─────────────────────────────────────────┐
│  大脑（Model）: 智能决策、知识储备         │
│  Harness（手脚）: 工具编排、状态管理       │
│  真实世界: 操作对象、约束条件、反馈机制     │
└─────────────────────────────────────────┘

理念: 引擎（模型）需要机甲（Harness）才能行动
```

**Harness职责清单**：

| 可以做 | 不可做 |
|-------|-------|
| 工具编排 | 替代智能决策 |
| 状态管理 | 生成创造性方案 |
| 错误处理 | 定义任务目标 |
| 执行闭环 | 评估执行价值 |
| 接口映射 | - |

### Self-Evolution三阶段速查

| 阶段 | 试错成本 | 稳定性 | Skill数量 | 模型依赖 |
|------|---------|-------|----------|---------|
| 探索期 | 高 | 低 | 0 | 强 |
| 压缩期 | 中 | 中 | 增长 | 中 |
| 固化期 | 低 | 高 | 固定 | 弱 |

**核心认知**：
- ❌ 拟人化自主学习
- ✅ 知识压缩与路径固化
- ✅ 跨模型一致性输出
- ✅ 提升可靠性、降低干预成本

### Multi-Agent协作速查

#### 单Agent三大局限

```
局限1: 上下文衰减
  超50%上下文 → 性能指数级下降

局限2: 任务偏航
  执行中途偏离初始目标

局限3: 缺乏验证
  单点失效无法及时发现
```

#### Multi-Agent三大机制

| 机制 | 模式 | 价值 |
|------|------|------|
| 角色分工 | 主Agent+观察Agent+评审Agent | 专业化、并行化、互检化 |
| 实时互检 | 执行Agent+监控Agent实时对比 | 及时发现偏航、纠正错误 |
| 重思考 | 执行→反思→调整→再执行 | 换角度复盘、逼近人类认知 |

### 模型能力演进速查

#### 从可视化到黑盒化

| 阶段 | 特征 | 原因 |
|------|------|------|
| 全程可视化 | 每一步可见 | 信任度低 |
| 关键节点可视化 | 关键决策可见 | 信任度中 |

```
交互: 文本 → 全模态（语音/视频/动作）
响应: 延迟 → 实时（毫秒级）

```

### 人类角色重新定义速查

#### AI本质

```
AI ≠ 替代人类
AI = 新型通用基础设施（解放人力）

类比:
  电力革命 → 解放体力劳动
  AI革命 → 解放重复劳动
```

#### 人类新角色

| 能力 | AI能力 | 人类优势 |
|------|-------|---------|
| 创造力 | 组合已有知识 | 创造新知识、新范式 |
| 判断力 | 评估可行性 | 定义价值标准、做判断 |
| 目标定义 | 执行目标 | 定义目标、提出需求 |

**分工原则**：
- AI：重复性执行（解放人力）
- 人类：创造性决策（提升价值）

## 核心认知突破速查

### 1. Harness不是大脑

```
❌ Harness替代模型智能
✅ Harness释放模型能力

类比: 引擎需要机甲才能行动
```

### 2. Self-Evolution不是自主学习

```
❌ Agent像人一样自主学习
✅ Agent通过知识压缩固化路径

本质: 提升可靠性、降低成本、支撑模型可替换
```

### 3. Multi-Agent协作弥补单Agent局限

```
单Agent: 上下文衰减、偏航、无验证
Multi-Agent: 角色分工、实时互检、重思考

本质: 逼近人类换角度复盘的认知优势
```

### 4. AI是新型通用基础设施

```
❌ AI替代人类
✅ AI解放人力

人类新角色: 创造力、判断力、目标定义
AI角色: 重复性执行
```
